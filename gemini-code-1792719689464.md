# Antgravity Spec: Gift Card & Micro-Payments PWA (v2 with Solana Pay)

## Core Architecture & Rails
- **Frontend**: Progressive Web App (PWA) optimizada para dispositivos móviles (Mobile-First).
- **Micro-Payment Rails**: 
  1. **Solana Pay (USDC / SOL)**: Cobros directos peer-to-peer desde $0.10 USD mediante códigos QR dinámicos y enlaces universales (`solana:`).
  2. **Gift Card Gateway API**: Validación de códigos de terceros (Steam, Tremendous, etc.) vía backend intermediario.

## Key Modules
1. **Solana Pay Checkout Module**:
   - Generación dinámica de URLs de pago utilizando `@solana-commerce/solana-pay`.
   - Creación de una **Referencia Única (Reference Key)** por cada orden para rastrear la transacción en la blockchain sin intervención manual.
   - Renderizado dinámico de código QR (compatible con Phantom, Solflare, Backpack).
   - Monitoreo en tiempo real (`findReference` / WebSockets) del estado del pago.
2. **Gift Card Redemption Form**: Interfaz para introducir códigos y validar montos de consumo.
3. **Ledger / Dashboard**: Balance en tiempo real que acumula micro-saldos desde $0.10 USD.
